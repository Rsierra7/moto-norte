# Moto Norte

Aplicación de escritorio en Python para la gestión de un taller de motos.

## Funcionalidades

- Gestión de inventario.
- Registro de ventas.
- Generación de facturas.
- Reportes de inventario y ventas.

## Tecnologías

- Python
- Tkinter
- MySQL

## Configuración de la base de datos

1. Copiar `.env.example` como `.env`.
2. Completar los datos de conexión a MySQL.
3. Disponer de la base de datos y las tablas utilizadas por la aplicación.

El archivo `.env` y las facturas generadas se excluyen del repositorio.

## Ejecución

Desde la carpeta principal:

python main.pyw
